## 第一部　對審查意見的逐條處理

審查意見共提出七組指摘。回查原件後，五組完全成立，一組部分成立，一組須反駁。以下逐條記帳。

### 1. 法規三項指摘——全部成立，而且問題比審查意見指出的更大

已重開總統府公報第5816號（1994）、第6666號（2005）、第7226號（2015）三件原件，結果如下：

| v1 的敘述 | 原件所示 | 判定 |
|---|---|---|
| 2005年學生會成為法定組織 | 1994年第17條（全文32條）已有「保障並輔導學生成立自治團體」與「經選舉產生之學生代表出席校務會議」；2005年新增的是「學生會」一詞、當然會員、會費、代收 | 部分錯誤，須改寫 |
| 2015年規定不得少於十分之一 | 十分之一首次入法在**2005年第33條第1項**，2015年只是移列第15條並加無條件進位 | 錯誤 |
| 2015年申訴範圍擴及其他措施與決議 | 2005年已含「其他措施及決議」；2015年增列的是「**行政處分**」 | 錯誤 |

原件另揭露三件 v1 與審查意見都沒有提到的事：

- **1994年版全文無任何學生代表比例下限。** 唯一的比例規定是教師代表不得少於二分之一。「學生代表入席」與「席次有保障」相隔十一年。
- **2015年新增無條件進位規則**（第15條第3項）。這對小型學校有實質意義：會議人數49人時，十分之一由「4人」變成「5人」。此點從未被討論。
- **專科學校法的學生會條文遲至2014年才入法**，比大學法晚九年；且其第42條第4項**迄今未加入「行政處分」**，申訴範圍停留在大學法2005年版的用語。也就是說，2015年那次救濟程序的升級，專科生沒有同步享有。

> 【按】這推翻了 v1「以大學法統攝大專」的作法，也提供了一個現成的、可指認的法制不對等。

### 2. 「黨團協商增訂」的推論——成立，須收斂

審查意見指 v1 把「在哪裡加入」推成「由誰設計」，跨了一步。成立。

實際查證結果更嚴格：立法院議事暨公報資訊網全站 robots 禁止抓取，已定位到兩份相關公報 PDF 路徑（第94卷第51期教文委員會審查紀錄、院會紀錄）但無法取得。**此說目前無法證實，也無法否證。**

v2 唯一可寫的句子：教育部人權教育資源網刊載之文章載有此說；該說為網站刊載之作者論述，非官方認定，亦未經協商原件佐證。

唯一可留的旁證是體例觀察，且須標【按】：比例規定屬校務會議組成事項，2005年卻置於「學生事務」章第33條，2015年又搬回第15條。此一位置錯置與「非行政院版原文」的說法相容，但相容不等於證實。

### 3. 施行細則第26條——應補，已補

【引】《大學法施行細則》第26條第2項：「學生會收取會費或學校依學生會請求代收會費，不得列為完成註冊程序之必要條件。」

此條把四件常被混為一談的事分開：當然會員／學生會有收費依據／學校有代收義務／能否以註冊強制繳費。前三者成立，第四者明文否定。

### 4. 自由之愛年份——成立

臺大校史館的序列確實顯示1985、1986、1987是不同事件。v1 把抗爭傳統、組織形成與一次具體行動混成同一個起點，應改。

但校史館該文有兩處問題須標明：它把運動起點記為1986年10月而非「下半年」，且**完全不提大新社停社處分**。另外，該文稱1985/5/11已「以511臺大學生日為由」遊行——「511臺大學生日」一詞是否當時即有，抑或1987年回溯命名後倒填，未能確認。這是典型的回溯命名風險。

連署人數三個數字，查證結果比 v1 與審查意見都更具體：186對應立法院請願書、1,865對應校內連署、18,000對應跨校連署。但**民報稱1987/3/24請願書是「由一千八百位台大學生連署」，與186直接矛盾，相差十倍**。三種解釋皆為假說，無一經證實。此項列為不得承重使用。

### 5. 四六事件人數——成立，且 v1 的解法本身有誤

v1 說「需要以檔案局資料為準」。這個解法不成立，理由有二：

其一，機關撰寫的導覽文與機關保存的原始檔案，證據性質不同。其二，實際查證發現檔案局相關頁面已改版或下架（art.archives.gov.tw 的四六事件頁 302 重導向至首頁），網路上根本取不到。

正確的解法是審查意見指出的口徑辨認。查證已完成，得出四項分辨（詳見查證檔三）：被帶走≠留置≠收押≠判刑；名冊≠被捕數；單校≠合計；當時報導≠後來回憶。

一項重要後續：臺大1997年《四六事件資料蒐集小組總結報告》已被臺大自己的後續研究（陳翠蓮、李鎧揚《四六事件與臺灣大學》）實質取代——該書編者明言1997年報告「過於簡略、並有不少待商榷之處」，決定重寫而非修訂。故1997年報告不宜再作承重引用。

### 6. 量化資料寫法——成立，且原始表顯示問題更嚴重

已取得青年署112年度報告表4-3-13原始表（A級，PDF檢視器逐格判讀）。

審查意見指出的三項限制全部成立，但還漏了兩項：

- **級距本身有設計瑕疵。**「10%以下」與「11%~20%」之間有斷裂，投票率落在10.1%~10.9%者無格可歸；「21%~30%」與「30%以上」在30%這一點重疊。
- **若改以有效填答校為分母**，109學年為52/88＝59.1%、111學年為66/87＝75.9%，與以124校為分母的42%、53.2%差距甚大。由於未填答校數逐年不同（36／31／37校，占124校的29.0%→25.0%→30.0%），跨年比較也被扭曲。

另須警示：以 AI 摘要工具讀取該報告時，曾發生編造表格級距的情形（謊報為「0-20%／21-40%／…」等距切法）。凡先前以摘要工具取得之數字，一律作廢重查。

### 7. 核心論證與時間順序——**部分反駁**

這是唯一須反駁的一條。

審查意見的關鍵反證是：「臺大學生會官方回顧已指出，1996年會長選舉投票率便跌破20%」，據此要求重新檢驗「2005年法律化造成衰退」的時間設定。

查證結果：**此一反證溯源失敗。** 找不到任何可徵來源記載1996年臺大會長選舉投票率。目前流通最完整的臺大歷年投票率資料集（王宏恩整理，1988–2023），明確標註1992、1993、1994、**1996**、1997、1998各年資料闕如。

而且找到了更可能是訛傳源頭的事實。【引】該資料集（王宏恩整理，1988–2023）的原始註腳逐字如下：

> 「\*許多為報紙報導的估計值
> \*\*1995年前研究生不被算進學生會投票
> \*\*\*1996年前有20%投票率門檻，後來廢除」

「1996年前有20%門檻」極可能被轉述成「1996年跌破20%」。

**但這不代表 v1 的法律化悖論因此成立。** 上述註腳的前兩條才是真正的致命限制：早期數字「許多為報紙報導的估計值」，且「1995年前研究生不計入分母」。

> 【按】**1996年前後的臺大投票率，在分母定義上根本不可比。這條時間序列兩邊都不能用來論證。**

所以 v2 採取的立場是：審查意見的結論（不應把法律化悖論當成整部歷史的主軸）**成立**，但它所依據的反證**不成立**。真正的理由不是「1996年就已經很低」，而是「早期資料的分母定義不一致，無法支持任何一種時間順序的主張」。

這個差別很重要。若照審查意見的理由改寫，等於用一個未經查證的數字去推翻另一個未經查證的推論，只是把錯誤換了一個方向。

## 第二部　研究設計 v2

### 主問題

採納審查意見的改寫方向，但收緊措辭：

> 【按】**相同或逐漸強化的法律保障，為什麼在不同校園產生高低懸殊的組織存續、參與程度與政策影響力？**

這個問法有三個好處：保留運動與制度的張力；容許制度化產生正面、負面或混合效果；把「跨校差異」設為分析對象而非雜訊。

### 四個必須分開的依變項

v1 把它們全放進「自治興衰」，這是審查意見指出的核心缺陷。v2 拆為四項，各有可觀察指標：

| 依變項 | 指標 | 現有資料狀況 |
|---|---|---|
| **組織存續** | 是否曾中斷、中斷原因、重建方式、門檻設計 | 青年署表4-2-8（A級，124校）；各校選罷法（多數溯源失敗） |
| **選舉參與** | 投票率、候選組數、廢票率、同額競選比例 | 青年署表4-3-13（A級，但級距有瑕疵）；臺大選委會公告（A級，僅近兩年） |
| **行政自主** | 財務自主程度、會費收取率、資訊公開程度、法人地位 | 各校學生會官網（高科大、雲科大、臺科大為A級） |
| **政策影響力** | 提案通過紀錄、代表產生方式、出席率 | 個案零散，須自建 |

**關鍵發現：這四項並不同步。** 技職體系的資訊公開程度不亞於一般大學（高科大設行政中心、學生議會、學生評議會三部門，章程、預算法、決算法、財務書表全部上網），但無任何一所科大的投票率資料可得。**運作有法制 ≠ 參與度高，不得由前者推論後者。**

### 分期（六期）

採審查意見的分期骨架，但依查證結果調整三處：第二期的斷點改為1972年（法源廢止年），第三期起點改為1982年（普選運動起點），第六期起點採2019年（台學聯成立）。

| 時段 | 研究重心 | 錨點（★＝A級原件） |
|---|---|---|
| **1945–1949** | 戰後組織重建、自治規範與政治整肅 | 1946/2 學生自治會規則；1947/12 修正；1948 臺大各學院學生自治會聯合會；1949/4/6 四六事件 |
| **1950–1972** | 黨國體制的組織收編 | 1952/10/31 救國團成立；1954 專科以上實施軍訓；**1972/11/11 教育部廢止《學生自治會規則》** |
| **1973–1993** | 法源真空下的普選運動與校園改革 | 1982 臺大普選事件；1986 大新社停社與自由之愛；1987/3/24 立法院請願；1988/3/16 代聯會改為學生會；1990/3 野百合 |
| **1994–2004** | 自治入法後的校內落實與分化 | ★1994/1/5 大學法第13、17條；★1994/8/26 施行細則訂定；1998 反高學費行動聯盟；2001 成大MP3事件 |
| **2005–2018** | 學生會法制深化與資源問題 | ★2005/12/28 第33條；2006/8/16 施行細則第26條；2008 首次全國學生自治組織調查；★2015/12/30 第33-1、33-2 |
| **2019–2026** | 全國聯合組織、疫情衝擊與席次爭議 | 2019/4/1 台學聯成立；2021/4/20 台學聯法人登記；2022/5 修法初審通過後停擺；2026/9 教育部發函 |

**1972年這個斷點是 v2 的新發現。** 教育部廢止《學生自治會規則》後，至1994年大學法修正為止，大專校院學生自治組織**沒有中央法規層級的法源**，改由各校訓導體系依行政裁量運作。這二十二年的法源真空，恰好構成日後「自治入法」的反面背景。

【存疑】此點目前僅有曾建元（2020）一篇政論專欄轉述（其引洪三雄1993），為C級。**寫入正文前必須調閱教育部公報或《教育法令》彙編原件，廢止令文字號未取得。** 若此點無法坐實，第二、三期的斷點須回到1981/1982。

另：日治前史納為短篇前史，用以釐清「自治」與學生組織的不同制度脈絡；**除非找到人員、組織或規則的承續證據，不預設它與戰後學生會有直接延續關係。**

### 四組理論框架（依審查意見調整用法）

| 框架 | v1 的問題 | v2 的用法 | 可檢驗的推論 |
|---|---|---|---|
| 政治機會結構 | 簡化為國家越開放參與越高，再宣稱無法解釋當代 | 比較**國家層次開放**與**校內決策封閉**的落差，並分析盟友、議程入口與反對力量 | 校內決策開放程度（席次比例、產生方式）應與參與程度相關，而非國家層次 |
| 法律化悖論 | 把權利入法等同動員誘因消失 | 拆成四個機制分別檢驗：資源增加、行政負擔、專業化、動員減少 | 若成立，應觀察到幹部工作量上升而選舉競爭下降 |
| Hirschman 退出／發聲 | 把社群發文直接當作退出 | 區分退出組織、轉換發聲管道，以及線上線下是否互相促進 | 網路聲量高的校園，選舉參與不必然低 |
| Bourdieu 場域 | 由幾位成功政治人物推論菁英再生產 | 比較參與前資源、參與中取得的資本、畢業後不同去向 | 須有非菁英路徑的幹部作為對照組 |

**「頂大、人社科、北部較活躍」須先定義活躍。** 投票率、抗爭頻率、媒體能見度、幹部人數可能呈現完全不同的排序，不能拿其中一項替其他項作證。查證已提供一個反例：技職體系的制度化程度高，但無資料可證其參與程度。

### 競爭解釋（列為變項，不預先宣告為原因）

疫情、實習與工讀時數、通勤、組織交接品質、學校規模、退場壓力、門檻設計。

其中「門檻設計」是查證中浮現的最可操作變項：青年署《大專校院學生會運作原則》（2022/6/30修正）全文**未規定選舉門檻或最低投票率**，各校門檻（東吳8%／1200人、成大2%、政大昔15%）**皆為各校自訂**。而成大2%門檻至2026年仍存續，未達門檻的效果是「視同重新辦理之補選」而非解散。

> 【按】**這說明倒會的關鍵可能不在「有無門檻」，而在門檻高度與未達門檻的法律效果設計。** 但因東吳條文溯源失敗，此對比目前只能停在假設。

### 個案選擇（避免以臺大代替全臺）

必須納入的對照組，及其現有證據狀況：

| 類型 | 個案 | 證據狀況 |
|---|---|---|
| 倒會後重建（證據紮實） | **政大2007年第8屆流選出缺** | B級，兩來源獨立（政大記憶網＋自由時報） |
| 倒會後重建（單一來源） | 東吳2021-22、高師大2022 | **C級，全部只有太報2026/1/20一篇。不得當成三個獨立個案。** |
| 門檻存續而不倒會 | 成大2% | B級 |
| 技職制度化 | 高科大、雲科大、臺科大 | A級（官網原件） |
| 私校與校方衝突 | 淡江2021宿舍費、文化2025校務會議結構 | B級 |
| 政策成功（校務會議） | 政大2018/1/5 廢除英語門檻，47:7通過，溯及既往 | B級，三來源互證 |
| 政策成功（學務會議） | **中山大學2022/5 心理健康假，首創** | B級 |
| 未成功的對照 | **文藻外語大學至今未廢除英語門檻** | B級，由該校學生會自己整理的文件載明 |

**兩項方法論修正：**

其一，**心理健康假走的是學務會議，性別友善宿舍走宿舍管理與性平系統，只有英語門檻走校務會議。** 若研究設定為「在校務會議推動成功」，會系統性漏掉學生自治最實際的戰場。v2 改稱「校級正式會議」。

其二，**代表產生方式本身就是變項。** 三校同受十分之一下限拘束，但產生方式落在完全不同的三點：高雄大學純推派、中山大學混合制加公開招募兜底、勤益科大普選。中山的「公開招募兜底」條款尤其值得注意——它等於制度性承認推選常常湊不滿人。

## 第四部　1/10→1/8→1/5 的正確寫法

v1 把這三個數字畫成已發生的制度演進，審查意見指摘成立。查證後可補上一項 v1 與審查意見都沒說的事：

**1/8 不是2026年新形成的共識，而是2022年校長團體的談判底線，被四年後的教育部接受為政策目標。**

【引】私立四大協會2022/5/24聲明：「如需調整以順應強化學生參與校務之需求，則建議以教育部版本的八分之一之比例為妥，以免過度放大比例，使權責不符。」

正確的三層寫法：

| 層次 | 狀態 | 證據 |
|---|---|---|
| 現行法律下限 | 十分之一（大學法§15II②） | A級 |
| 行政指導 | 教育部鼓勵提高至八分之一，辦理情形納入補助核配參據 | B級，函文日期文號未得 |
| 倡議目標 | 台學聯主張至少五分之一；高教工會主張三分之一 | B級 |

這三者是不同規範層次與政治主張的並存，不是時序。

【同源警告】國立大學校院協會（2022/5/23）與私立四大協會（2022/5/24）的聲明都舉「劍橋大學3名學生代表，不到八分之一」為據，說法高度雷同，**疑為同一份論據稿互相引用**。若要論證「兩陣營獨立反對」，須先排除同源。

【線索】國立協會當年主張「待教育部委託報告出爐後」再議——所指極可能就是青年署的學生會概況調查。**校長團體要求等待的那份報告，後來成了論證學生參與低落的主要資料來源。** 這條線值得追。
