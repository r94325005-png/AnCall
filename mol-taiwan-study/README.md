## 常見問題

**Q：如果 Mol 的書我沒讀過怎麼辦？**  
A：Claude 會幫你從英文版本裡提取。但如果可能，讀一讀第四章「Relating」（30-40 分鐘）會讓討論更有根據。

**Q：「在地化檢核代理」是什麼？為什麼要分開做？**  
A：因為框架偷渡很容易被「說不出來」。一個人寫內容時，同時做自我檢核，容易被說服、被框架綁住。分開做，檢核者的工作單純：只標記預設，不碰內容。

**Q：「反收斂」是什麼意思？**  
A：別強制把相反的想法調和成「各有各的好」。如果台灣和西方對「關係」的理解根本相反，就保持相反，探索為什麼。那個「為什麼」才是本土化的發現。

**Q：不可譯清單有什麼用？**  
A：它是一份「語言發現」的記錄。每個不能譯清楚的詞，都暴露了台灣的概念系統和西方的差異。最後的清單可以作為「本土化研究找到了什麼」的一份清點。
