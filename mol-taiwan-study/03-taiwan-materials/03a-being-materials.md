# 03a：台灣飲食素材蒐集「存有（Being）」

---

## 場景 1：中醫身體觀與飲食

### 素材 1-1：氣的通透身體
**來源**：中醫基礎理論（黃帝內經、傳統醫學）；台灣日常食補實踐  
**場景描述**  
台灣家庭的日常食補語境：
- 「最近太累了，要補氣」——氣是流動的，可以被補、被耗、被阻
- 「這個人氣虛，所以容易感冒」——身體的狀態由氣的充盈決定
- 「吃薑黃補陽氣」、「紅棗補血氣」——食物被理解為氣的載體
- 廚師煮食時：「這道菜的火候要夠，才能把氣逼出來」——食物有氣，烹飪是釋放食物之氣的過程

**身體觀核心**  
中醫的身體不是 Merleau-Ponty 的有界身體。氣在身體內外流動：
- 身體吸收天地之氣（呼吸、飲食、環境）
- 身體也向外散發氣（出汗、呼氣、說話）
- 身體邊界是**可滲透的**：外部世界（天氣、季節、食物）持續進入我，我也持續流入世界
- 身體不是「我的世界的錨點」，而是**天地循環的一個節點**

**語言線索**
- 「氣虛」= 身體從外部獲得的不足，或內部消耗太多——身體是開放系統
- 「補氣」= 從外部（食物、藥物、環境）補充身體的虧欠——身體主動從外界汲取
- 「通氣」= 氣的流動被阻礙，需要被疏通——身體是管道，不是容器
- 「養氣」= 長期的、生活方式層次的氣的維護——身體是持續的修養過程

### 素材 1-2：醫食同源的本體論
**來源**：中醫「藥食同源」原則；台灣飲食文化  
**場景描述**  
「藥食同源」（或「醫食同源」）是台灣日常生活中耳熟能詳的說法：
- 老薑、紅棗、枸杞既是食物也是藥物
- 平常吃這些東西不是「治病」，而是「預防」、「調養」
- 台灣人去看中醫，醫生常說「要配合飲食調整」、「吃這道菜比吃藥還好」
- 煮四神湯（薏仁、蓮子、山藥、茯苓）：「這不是藥，是日常食補，要常吃」

**身體觀核心**  
「藥食同源」預設了一個根本不同的身體觀：
- 食物不只是營養（卡路里、蛋白質……），而是具有**特性的物質**（寒熱溫涼、五味……）
- 食物的特性和身體的狀態**互相對應**：虛寒的人補溫熱的食物、燥熱的人吃清涼的食物
- 身體是一個**關係性的、動態的場域**，而不是固定的機器
- 身體的「正常」不是固定的，而是**當下的平衡**（這個人、這個季節、這個生命階段的平衡）

**語言線索**
- 「補」= 不只是添加，而是恢復平衡
- 「調」= 調整、調和——身體是被「調」的，不是被「修理」的
- 「體質」= 每個人有自己的體質，沒有普遍的「正常」
- 「當季的食物」= 身體和季節的同步（春要升發、夏要清涼……）

### 素材 1-3：天人相應的飲食節奏
**來源**：傳統節令飲食、台灣家庭的節氣食補  
**場景描述**  
台灣家庭跟著節氣調整飲食：
- 冬至：吃湯圓、進補（十全大補湯、薑母鴨、麻油雞）——「冬至補冬，補嘴空」
- 春天：吃春筍、春捲、清淡食物——「春天要升發，不能補太重」
- 清明節後：不吃冰——「清明過後，清明雨過，身體還脆弱，吃冰傷身」
- 端午節：吃粽子、雄黃酒——「午時節，辟邪氣」

**身體觀核心**  
這套飲食節奏預設了「天人相應」的身體觀：
- 身體不是獨立於自然的，而是**與天地節律同步**的
- 「什麼時候吃什麼」不是個人選擇，而是**宇宙秩序的一部分**
- 偏離這個節律就是「逆天」——不只是對身體不好，而是倫理性的錯誤
- 飲食把人安置在天地的時間流中，而不是讓人作為自主主體凌駕於自然

**語言線索**
- 「補冬」= 冬天是補養的季節，身體和季節同步
- 「不能補太重」= 春天的升發原則約束飲食選擇
- 「傷身」= 不符合節律的飲食傷害的不只是個人身體，而是破壞了天人的秩序
- 「辟邪氣」= 食物具有應對宇宙中負面力量的功能

### 素材 1-4：食物的五行與身體
**來源**：中醫五行理論；台灣日常食補語境  
**場景描述**  
五行（木火土金水）與五臟（肝心脾肺腎）與五味（酸苦甘辛鹹）的對應：
- 「酸入肝，多吃醋對肝好」
- 「苦入心，喝苦茶清心火」
- 「甘（甜）入脾，脾胃虛的人要多吃甘味食物」
- 台灣媽媽說：「你最近臉色很差，脾胃虛，要多煮山藥排骨湯補一補」

**身體觀核心**  
這個系統把食物、身體、宇宙聯繫在一起：
- 身體的每個部分和宇宙的元素**有對應**
- 飲食是一種**宇宙性的調節**：透過食物，調整身體在宇宙秩序中的位置
- 這個身體不是生物性的機器，而是**宇宙微縮**（身體 = 天地的縮小版）
- 「我」的身體不是我獨自擁有的，而是天地秩序的一個展現

**語言線索**
- 「入○臟」= 食物和身體器官有直接的流動關係
- 「清○火」= 食物可以調節宇宙元素在身體中的失衡
- 「補一補」= 補的不只是身體，而是身體在宇宙秩序中的位置
- 「體質」= 你在五行中的傾向，不是普遍的「正常」

### 素材 1-5：吃進去的就是你——身體的積累觀
**來源**：台灣家庭食補智慧；坐月子文化  
**場景描述**  
台灣說法：
- 「你吃什麼，你就是什麼」——不只是比喻，而是字面意義
- 「孕婦要多吃好東西，孩子才會聰明漂亮」——母親的飲食直接塑造孩子的存有
- 「這個人皮膚好，一定吃得好」——外在狀態反映飲食積累
- 「老人家多吃核桃補腦」——食物的形狀和功效有對應（核桃像大腦，所以補腦）

**身體觀核心**  
「以形補形」（形似的食物補對應部位）和「飲食累積成你」的觀點：
- 身體不是固定的，而是被飲食**持續地、累積地構成**
- 「我」不是一個先於飲食存在的主體，而是飲食積累的**結果**
- 身體的邊界不只是皮膚，而是整個飲食-環境的網絡
- 「誰」= 「吃了什麼的積累」

**語言線索**
- 「你吃什麼，你就是什麼」= 存有由飲食構成，不是先驗的
- 「以形補形」= 食物的形狀攜帶的意義進入身體
- 「補腦」= 食物的特性在身體中轉化成能力
- 「積累」= 身體是過程，不是固定的結構

## 場景 2：身體邊界的台灣想像

### 素材 2-1：「吃到肚子裡就是自己的」
**來源**：台灣俚語與飲食觀念  
**場景描述**  
「吃到肚子裡就是自己的」這句話在台灣有多重用法：
- 字面意義：某人吃了某樣食物，無論是什麼來源，現在都是他身體的一部分
- 引申意義：強調「進入」之後的轉化——不再是外部的，而是「我」的
- 但同時：「吃到肚子裡就是自己的」也可以用來描述：你吃了祖先的食物、神明的食物，祖先/神明的力量也進了你

**身體觀核心**  
這句話暴露了台灣身體觀的一個核心特徵：**進入即轉化即成為**。
- 吃進去的不只是食物，也可能是力量、祝福、疾病、汙染
- 身體的邊界在吃的瞬間開放，外部的「他者」進入「我」
- 「我」的邊界由吃的歷史決定

### 素材 2-2：身體是借來的
**來源**：台灣民間宗教觀；佛教影響  
**場景描述**  
台灣民間說法：「這個身體是借來的」——父母給了身體，天地給了生命力，死後要還回去。
- 因此：好好照顧身體是倫理義務（不是自己的，要好好保管）
- 飲食是「照顧借來的身體」的實踐
- 不好好吃飯 = 不孝（不照顧父母給你的身體）

**身體觀核心**  
身體不是你的私有財產，而是**借的、暫時的、有義務歸還的**：
- 身體的所有權不在個人手上
- 飲食是這個借用關係的維護實踐
- 「我」不是身體的主人，而是身體的**暫時保管者**

**語言線索**
- 「借來的身體」= 存有的非自主性
- 「好好保管」= 身體是一種倫理責任，不是自我表達的工具
- 「不孝」= 飲食失職 = 倫理失敗

## 小結

台灣飲食素材中浮現的身體觀與 Merleau-Ponty 的根本差異：

| | Merleau-Ponty | 台灣（氣、養、天人相應） |
|---|---|---|
| 身體邊界 | 有界、穩定 | 通透、持續與天地交換 |
| 身體中心性 | 「我」是世界的錨點 | 「我」是宇宙循環的一個節點 |
| 身體同一性 | 穩定的「我」 | 飲食積累的結果，持續在變 |
| 身體主權 | 「我的身體」 | 借來的身體，我只是保管者 |
| 身體知識 | 本體圖式（個人的習慣性知識） | 天地節律（宇宙的節奏） |
