# 2. 認識（Knowing）：從感官階序到「體知/嘗」的身體認識論

## 2.1 Korsmeyer × Mol：看見即認識

西方哲學有一個古老的偏見：**視覺是最高貴的感官**。從柏拉圖把真理比作「陽光照亮的洞穴外世界」，到笛卡爾把清晰可見的「明確觀念（clear and distinct ideas）」作為知識的標準，看見（seeing）和知道（knowing）在西方語言中幾乎是同義詞——「我看清楚了」就是「我知道了」。

Carolyn Korsmeyer 梳理了這個傳統所產生的**感官階序**：視覺、聽覺居上位（距離、抽象、可分析）；嗅覺、觸覺、味覺居下位（接觸、肉體、不可言說）。其中味覺是最低的，原因明確：視覺可以保持距離（我看一幅畫不必碰它），但味覺必須讓對象**進入**我的身體，只有把食物放進嘴裡才能嘗。這種必要的身體接觸使味覺看起來「太動物性」，因此不是認識，只是本能。

Korsmeyer 的策略是為味覺辯護：味覺也能有美學經驗，也能有細膩的判斷，它不比視覺低等。但 Mol 指出這個策略的問題：**Korsmeyer 仍然在感官階序的遊戲規則裡競爭**——她試圖讓味覺升等，但沒有質疑為什麼要有這個階序。

Mol 的問題更根本：如果我們不是從視覺（距離、客觀、不改變認識者）出發，而是從**嘗（tasting）**出發——讓食物進入身體、讓身體被改變——我們會得到什麼樣的認識論？

她的答案是：一種**雙向的、具身的、改變認識者的認識**。我嘗食物，食物同時也「嘗了」我——它在我的感受器上留下印記，改變了我此刻的狀態。這不是從「外部主體觀察客體」的認識，而是**主客互相滲透的認識**。

但 Mol 的「嘗式認識論」還是缺了一個維度：她描述的「嘗」是當下時刻的、個人身體的經驗。她沒有問：嘗的能力是怎麼來的？如果嘗是一種認識方式，它是可以被訓練的嗎？被誰訓練？怎麼傳授？

## 2.2 台灣素材：工夫知識、火候判斷、體知的傳授

台灣廚師文化給出了明確的回答。

老廚師說：「這個不用量，感覺對了就是對了。」這句話在西方認識論裡是危險的——因為「感覺」沒有客觀標準，無法被量化、被驗證、被普遍化。但在台灣廚師的實踐裡，這恰恰是最高等的認識：不依賴外部測量（溫度計、計時器），而是依賴**身體積累的判斷能力**。

問題是：這種「感覺對了就是對了」是怎麼來的？老廚師接著說：「你要做幾百次，身體才會記得。」不是幾百次觀察（視覺），而是幾百次**做**——切、翻、聞、嘗、聽（油爆的聲音）——讓身體在反覆的實踐中建立起一套**自己的認識標準**。

這不是 Mol 的「嘗」。Mol 描述的是任何人在吃東西時都可能有的感受。台灣廚師的「感覺對了」是**有門檻的**——不是任何人都能做到，需要師傅帶、需要時間積累、需要正確的環境。學三年才開始「摸到一點點火候」——這個「摸到」的說法很精確，就是用手（觸覺）比喻認識的觸達。

品茶文化把這個更細緻地展開。台灣茶人說「入喉後有回甘，好茶」——最終的認識標準在喉嚨（進入更深的身體），而不在嘴（表面接觸）。而且「喝一千泡茶，才能說你開始認識茶」——認識有程度，沒有終點，需要長期的身體被茶訓練。這是一個完整的**嘗式認識的學習系統**，從師傅到徒弟、從親身實踐到身體記憶。

市場的老廚師挑食材時也是一課認識論：「你用看的，要用手摸、用鼻子聞，才知道好不好。」視覺只是入口，最終的判斷要靠觸覺（彈性、溫度）和嗅覺（新不新鮮）。這**顛倒了 Korsmeyer 的感官階序**：在食材認識中，嗅覺/觸覺 > 視覺。不只是「味覺也不差」，而是「視覺反而是最膚淺的認識入口」。

## 2.3 對話：「體知」如何顛倒感官階序

台灣的這套認識實踐有一個詞可以捕捉它的輪廓：**體知**（bodily knowing / embodied knowledge）。但「體知」本身也有不可譯的地方：它不只是「身體性的知識」（embodied knowledge，西方術語），而是暗含了：這個知識是**在身體中積累的、通過身體傳授的、只能在身體實踐中習得的**。

體知對 Korsmeyer 的感官階序做了什麼？不只是「讓味覺升等」（Korsmeyer 的策略），而是**直接廢除了這個階序的前提**。

感官階序的前提是：距離 = 客觀 = 高等認識。視覺好，是因為視覺可以保持距離、客觀觀察，而不被對象改變。

但台灣的體知說：**被對象改變，恰好是認識達到的標誌**。老廚師被幾百次的炒、切、聞、嘗改變了他的身體，正是這個改變讓他能說「感覺對了就是對了」。茶人被一千泡茶改變了他的味覺，正是這個改變讓他能識別好茶。認識者被認識對象改變——這不是認識的失敗（不客觀、太主觀），而是認識達成的標誌。

這對西方認識論的衝擊是：**「不被改變」的主體無法達到最深的認識**。保持距離的觀察者看不到老廚師看到的東西，因為他沒有被幾百次實踐改變過的身體。認識不是「主體中立地觀察客體」，而是**「主體被客體改變之後，才能認識客體」**。

更進一步：台灣的體知不是個人的。廚師的身體知識來自師傅的身體知識，師傅的知識來自他的師傅……這是一條**師徒傳承的身體知識鏈**。認識的主體不是孤立的個人，而是這條傳承鏈上的一個節點——類似於「存有」章的「天地節點」，認識主體也是知識傳承鏈上的節點。

## 2.4 三態並陳

### 能旅行的

兩個系統都承認：感官的認識不能完全被語言化。Mol 說「身體性的認識有不可言說的部分」；台灣說「感覺對了就是對了，說不清楚」。**認識的不可語言化**是共通的。

### 水土不服的根本對立

| 面向 | Korsmeyer / Mol | 台灣（體知、工夫）|
|-----|-----------------|----------------|
| 感官階序 | 視覺居上（Korsmeyer）/ 飲食顛倒了視覺中心（Mol） | 嗅觸味覺 > 視覺——「用看的不夠，要用手摸鼻子聞」 |
| 認識者和認識對象的關係 | 主體觀察客體（Korsmeyer）/ 主客互相滲透（Mol） | 主體被客體長期改變才能認識——改變是認識達到的標誌 |
| 認識的時間 | 當下時刻（看見 / 嘗到） | 幾百次、幾十年——認識是長期積累 |
| 認識的主體 | 個人（個人的感官、個人的身體） | 師徒傳承鏈上的節點——認識主體是集體歷史的積累 |

**根本對立**：Mol 的「嘗式認識」是即刻的、個人的。台灣的「工夫知識」是長期的、集體的（師承）、有門檻的（不是任何人都能做到）。這不是同一套認識論的兩個版本，而是對「什麼是認識」有根本不同的假設。

### 反向照亮

**台灣工夫知識對 Mol 的質疑**：如果嘗是認識，誰的嘗算數？

Mol 說「嘗讓身體被改變，這是認識」。但在台灣的食材鑑別和品茶文化裡，**不是任何人的嘗都算數**。老師傅的嘗是認識；新手的嘗只是個人感受，還不算認識。這個差異靠什麼決定？靠師承、靠積累的工夫、靠年資。

這質疑了 Mol 的認識論的民主性假設（任何人嘗了都有認識）。台灣說：認識是有階序的，但這個階序不是感官的（視覺 > 味覺），而是**工夫的**（深厚積累 > 零工夫）。顛倒了感官階序，但保留了認識的階序——只是換了一個標準。

## 2.5 不可譯發現

- **體知**（embodied knowledge）：英文版本只有「具身的知識」，但體知還暗含：知識在身體中積累、師徒傳授、需要時間和實踐。Knowing with and through the body 都還不夠精確
- **工夫**（craft / skill / mastery）：工夫涵蓋時間投入＋技藝積累＋道德修養——英文任何單詞都只捕捉一層
- **火候**（heat control / timing）：火候是物理的（溫度）＋美學的（恰到好處）＋倫理的（對食材的尊重）。任何翻譯都割裂了這三層
- **嘗**（taste / try / attempt）：嘗作為認識動作，同時是「嘗試」和「品嘗」——認識即是嘗試進入，不能保持距離

## 小結

這章的發現：Mol 把 Korsmeyer 的感官階序顛倒了（嘗比看更根本）。但台灣的「體知—工夫—火候」更進一步：**認識是長期積累的、師承傳授的、被認識對象長期改變之後才達到的**。這不只是「嘗式認識」的台灣版本，而是一個有完整傳授系統的認識論——認識的主體不是孤立的個人，而是傳承鏈上的節點。

Mol 問「如果以嘗取代看，認識論會怎樣」。台灣的工夫知識回答說：認識比你想得更難，需要更長的時間，而且你一個人做不到——你需要師傅，需要一條傳承鏈。
