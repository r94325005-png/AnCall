# 3. 作為（Doing）：從主體施為到「養生/工夫/火候」的身體修養

## 3.1 西方行動理論 × Mol：誰在做這件事？

西方行動哲學有一個核心問題：**什麼是真正的行動？** 標準答案是：行動需要有意圖的主體。「我決定舉起手臂」是行動；心臟跳動不是（沒有意圖）；被人推倒不是（不是自己的意志）。行動者（agent）= 有意圖的自主主體；客體（object）= 被動地被行動改造的對象。

這個框架在飲食面前開始動搖。Mol 問：當我吃東西時，**誰在做？**

表面答案是「我」——我選擇吃、我咀嚼、我吞嚥。但仔細看：
- 我的食慾是「我的」意圖嗎？（飢餓感告訴我要吃，這是我決定的嗎？）
- 食物進入身體後，消化是「我」在做嗎？（胃酸、腸道蠕動，不是我控制的）
- 食物最終轉化成細胞、能量，這是誰做的？

主動和被動在飲食裡不是二元對立，而是**持續交纏的**。Mol 提出「tinkering」（修補、摸索）作為替代概念：不是有計畫的主體執行意圖，而是在給定條件下一點一點調整、試驗、回應。就像護士照顧病人，不是照著固定計畫走，而是隨時回應身體的信號，調整方案。

Mol 的 tinkering 打破了「主動行動者 vs. 被動客體」的二元對立，這是她的貢獻。但 tinkering 有一個明顯的限制：它是**當下性的**（現在調整）、**個體性的**（護士的摸索）、**實用性的**（解決眼前的問題）。

台灣飲食文化裡的「養生」、「工夫」、「火候」給了一個截然不同的方向——不是當下的摸索，而是**長期的、有方向的、倫理性的身體修養**。

## 3.2 台灣素材：養生、工夫、火候、集體的做

「最近在養生，早睡早起，吃清淡」——這句話描述的不是 Mol 的 tinkering（應對當下情況的調整），而是一種**生活方式的整體承諾**。養生不是問題解決（我現在不舒服，所以調整），而是**持續的、有方向的修養**：生命應該如何被對待？身體應該怎樣被照顧？

「養生」的時間尺度和 tinkering 完全不同。Tinkering 是「此刻調整」；養生是「整個生命的方向」。「老了就要懂得養生」暗示了養生是一種**人生進程中的修養課題**，不是偶發的調整行為。而且「懂得養生」需要學習——養生是一種需要積累的**智慧**，不是本能。

廚師的「工夫」把這個說得更具體。工夫不只是技術能力（我能把菜炒好），而是一種**時間性的德行積累**：學了三年才開始摸到火候，意味著做（cooking）的意義不在當下的結果，而在這個過程中身體的**漸進轉化**。工夫的廚師不只是「做到了」，而是「在做的過程中成為了一個有工夫的人」——做（doing）和成為（becoming）是同一件事。

「火候就是你對食物的尊重」——這句話把做（做菜）的目的說清楚了：不是讓廚師展現技術（以廚師為中心的做），而是**讓食材成為它本來最好的樣子**。這是一種**去中心化的做**：廚師的工夫是用來服務食材的，不是用來征服食材的。與 BMI 的做（醫療系統決定「正常」標準，然後規範身體去符合）完全相反——台灣的養生是「聽身體的，順應它的節律」，而不是「把身體改造成符合外部標準的形狀」。

辦桌的集體勞動揭示了做的另一個維度。誰在做辦桌這頓飯？一個人主廚、其他人殺魚切菜搬桌椅——**「做」不屬於任何一個人**，而是在一個集體的分工系統裡完成的。分工沒有正式指揮者，大家「看著做」——行動是在集體觀察和隱性協調中發生的，不是由單一有意圖的主體推動的。

「顧灶腳」的女性勞動則暴露了更複雜的問題：同樣的廚房動作，男性做是「工夫」（技藝、修養、可以被稱讚），女性做是「義務」（本分、不可選擇、理所當然）。**做（doing）的意義，被行動者的社會身份決定**，而不只是動作本身。

## 3.3 對話：「養生」如何鬆動主體/客體的二分

Mol 的 tinkering 說：沒有一個全知全能的行動主體，只有在現實中摸索的人。這是對「有意圖主體」的局部鬆動。

台灣的「養生」、「工夫」、「火候」做了更徹底的鬆動：**「做」的目的不是主體表達意圖，而是讓主體跟隨它所服侍的對象**。

養生不是主體對身體施加計畫（讓身體符合 BMI 標準），而是**主體聽從身體的節律**（七八分飽、配合體質、順應季節）。主體和身體的關係反轉了：不是主體指揮身體，而是身體在引導主體。

工夫的廚師在火候的判斷上也是如此：不是廚師決定食材應該怎樣（「我要把它炒到金黃」），而是廚師**聽食材的**（「這個食材在這個火候下有什麼變化？我要配合它的節奏」）。好的廚師不是征服食材，而是**讓食材成為它自己**。

這改寫了西方行動理論的核心結構：
- 西方版本：行動者（主體）→ 意圖 → 行動 → 改造客體
- 台灣版本：主體被客體（身體、食材、天地節律）引導 → 主體配合、服從、聆聽 → 客體（食材、生命）得以成為它本然的樣子

「做」不再是主體施加意志於客體，而是**主體跟隨客體的本然，讓它展開**。

更根本的差異在「做」的時間性。Tinkering 是即刻回應（現在調整）；工夫是**歷時的身體修養**（幾十年才有火候）。這讓「做」不再只是一個動作，而是一個人**成為什麼的過程**——你如何養生，決定了你成為什麼樣的人；你的工夫積累，決定了你成為什麼樣的廚師。做（doing）和存有（being）在台灣飲食文化裡是不可分的。

## 3.4 三態並陳

### 能旅行的

兩個系統都承認：「做」不是純粹主動意圖的執行，行動者總是在與環境、身體、材料的互動中調整。**行動的回應性**是共通的。

### 水土不服的根本對立

| 面向 | 西方行動論 / Mol | 台灣（養生、工夫、火候） |
|-----|-----------------|----------------------|
| 行動主體 | 有意圖的個人 / 摸索中的個人 | 長期積累的修養者；集體分工的成員；服從食材/身體的聆聽者 |
| 行動目的 | 達成目標 / 解決問題 | 讓事物（身體、食材）成為它本然的樣子；修養自身 |
| 行動時間 | 計畫-執行（當下）/ tinkering（當下） | 幾十年的積累；代際傳承的智慧 |
| 行動的倫理 | 技術性（有沒有達到目標）/ 實用性 | 倫理性（做菜展現對食材的尊重；養生是對生命的責任） |
| 行動標準 | 外部規範（BMI、效率） | 個體差異（體質）；服從本然（讓食材成為自己） |

**根本對立**：西方行動論的主體是從「我」出發的（即使 Mol 鬆動了它）。台灣的養生/工夫是從「被我服侍的對象」出發的——不是「我要做什麼」，而是「這個身體/食材/季節告訴我要做什麼」。這是主體性方向的根本反轉。

### 反向照亮

**「顧灶腳」對 Mol 的 tinkering 的質疑**：tinkering 是中性的摸索，但誰被允許 tinker？

Mol 說 tinkering 是在現實中的調整摸索——她的例子是護士。但台灣的廚房分工暴露了：同樣的廚房行為，被允許「摸索、調整、被稱讚為工夫」的是男性廚師；被期待「按規矩做、不許亂來」的是女性的家庭義務。

Tinkering 預設了行動者有空間摸索、有被承認的可能性。但現實中，**誰有空間 tinker，是被性別、階層、師承決定的**。Mol 的 tinkering 沒有問這個政治性問題。

## 3.5 不可譯發現

- **養生**（health cultivation / wellness maintenance）：養生是「養護生命」，涵蓋飲食、作息、心靈、倫理——英文版本只能捕捉生理層次，失去了道德修養的維度
- **工夫**（skill / craft / kung fu）：工夫是時間投入＋技藝積累＋道德修養的三位一體；任何英文翻譯都分裂了它
- **火候**（heat timing / cooking temperature）：火候是物理的＋美學的＋倫理的（尊重食材）；翻譯只能取其中一層
- **顧灶腳**（tending the stove area）：「守護爐灶」，但同時是女性被分配的義務空間——一個詞封裝了性別政治

## 小結

這章的發現：Mol 的 tinkering 打開了「主動行動者 vs. 被動客體」的二元之外的空間。台灣的「養生—工夫—火候」走得更遠：**做的目的不是主體實現意圖，而是讓被服侍的事物（身體、食材、生命）成為它本然的樣子**。

主體方向反轉了：不是從「我」出發，而是從「被我照顧的事物」出發。這讓「做」從技術問題變成倫理問題，從當下問題變成長期修養問題，從個人問題變成師承傳承問題。

Mol 的 tinkering 是西方個體主義的局部修正。台灣的工夫-養生是另一套「做的哲學」，它的前提（服從本然、長期修養、集體傳承）與西方的前提（自主意圖、當下調整、個體摸索）在根本上相反。
